## 📁 目錄結構說明

本倉庫依據官方推薦規範初始化，各目錄用途如下：

* `daily/`：每日學習打卡草稿與心得記錄。
* `tasks/`：課程指派任務與作業的證明存放處 (Proof of Task)。
* `experiments/`：程式碼測試、智能合約部署與開發實驗記錄。
* `handbook-feedback/`：對課程手冊與教材的反饋與修正建議。
* `hackathon/`：黑客松專案想法、組隊資訊與初稿準備。
* `submissions/`：正式提交給學校系統的作業與成果物。
* `templates/`：日常筆記範本目錄（內含 `daily-note.md` 與 `task-note.md`）。
* `profile.md`：個人簡介與 Web3 學習目標。
* `learning-plan.md`：個人的學習時間規劃與里程碑。
